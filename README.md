# 绿万家花妈妈生态游乐农场网站 V2.5

这是可直接运行和部署的响应式静态网站源码。当前线上临时域名为 `https://hmmncfarm-3vhg2mi.maozi.io/`，未绑定自有域名。

## V2.5 本版改动

- 首屏重新建立三级信息层级：农场全称为最大标题，“一个可以吃花、喝花、玩花的地方”为二级标题，生活金句为三级标题。
- 移除手机端始终占据屏幕底部的电话、微信、导航工具条。
- 参考 Apple 移动端官网，将预约入口收进顶部轻量导航，电话与导航保留在到访区，减少页面遮挡。

## V2.4 延续内容

- 首页把“一个可以吃花喝花玩花的地方”作为第一主标题，与“把日子过进花里，把快乐还给自然”形成品牌说明和情绪金句两层关系。

- 手机底部改为悬浮胶囊式电话、微信、导航操作，首页按钮、微信弹窗和复制提示重新设计。

- 结尾改为花海背景和半透明黑色蒙层，不再使用整块纯绿色背景。
- 删除所有面向开发者的页面说明，只保留游客需要看到的文案。

## 本地预览

源码没有外部运行依赖。可以直接打开 `index.html`；为了测试微信复制等 HTTPS/浏览器行为，建议使用本地静态服务器。

```bash
npm run build
```

构建输出目录为 `dist/`。Node.js 要求 `>=18`，不需要 API key 或环境变量。
