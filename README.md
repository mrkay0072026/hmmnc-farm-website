# 绿万家花妈妈生态游乐农场网站 V2.3

这是可直接运行和部署的响应式静态网站源码。当前线上临时域名为 `https://hmmncfarm-3vhg2mi.maozi.io/`，未绑定自有域名。

## V2.3 本版改动

- 改为真正的移动端优先设计：手机首屏、滑动画廊、价格分类、底部快捷联系均按单手操作设计，桌面端作为增强布局。
- 恢复第一版“大背景图＋大字标语”的沉浸感，首页使用第一版农场场景图，并明确标注为 AI 场景示意。
- 新增三组背景金句段落，包括“把日子过进花里，把快乐还给自然”，强化对自然、相聚和幸福生活的情绪表达。
- 单独游园改为 9.9 元/人并赠花卉一盆；在农场就餐的客人可随餐体验园区基础参观与游玩。
- 按最新清单重排餐标、课程、免费/收费游玩项目、教练导师和场地费用。
- 新增三张 AI 餐饮场景图：团体桌餐、羽衣甘蓝饺子宴、地锅鸡与菌汤砂锅土鸡，页面明确标注后续替换实拍。
- 游玩、课程和教练服务使用可切换标签，减少手机端长表格堆叠。

## 本地预览

源码没有外部运行依赖。可以直接打开 `index.html`；为了测试微信复制等 HTTPS/浏览器行为，建议使用本地静态服务器。

```bash
npm run build
```

构建输出目录为 `dist/`。Node.js 要求 `>=18`，不需要 API key 或环境变量。
