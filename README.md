这是一个**真正可运行**的响应式单页展示网站，不是单独的效果图。使用原生 HTML、CSS、JavaScript，静态部署，零外部运行依赖。

- 12大网页内容板块、9张AI场景示意图片、手机与桌面适配、滚动出现动画。
- 依据农场提供的原始清单，展示**全部5类收费/免费信息**并按类别筛选。
- 电话链接：`tel:13014583578`（移动端跳转系统拨号界面，是否需要最终确认由手机系统决定）。
- 微信预约：点击后尝试自动复制 `cjm13014583578`，并弹出复制结果及添加微信说明；复制失败时显示手动复制提示。
- 导航：高德地图搜索 `郑州绿万家花妈妈科普基地`，页面展示荥阳市014乡道与兴阳线交叉口东北140米。
- 营业时间：每天08:00—18:00。
- 9张图片为AI场景**示意**，并非农场实景；网站已对此明确标注。

## 本地打开 / 构建

直接双击 `index.html` 可预览静态页面，图片和布局不依赖安装依赖。部分浏览器在 `file://` 下可能限制剪贴板，正式 HTTPS 部署后测试。

```bash
npm run build
```

构建结果：`dist/` 目录，包含全部可直接部署的静态文件。无需 `npm install`，无需 API 密钥。

## 帽子云部署（独立应用，避免覆盖既有青年OPC网站）

1. 将本项目上传到具有帽子云授权的 **独立 GitHub 仓库**，或由 Codex 在已授权仓库中新建项目专用路径／项目（应使用独立站点，避免覆盖OPC）。
2. 帽子云控制台创建 **静态网站**，连接该仓库和分支。
3. 构建命令：`npm run build`；输出目录：`dist`；项目根目录：`/`。
4. 首次部署成功后，检查主域名、图片、手机操作、HTTPS。
5. 以后改动仓库代码再推送，帽子云可自动触发部署。

详情参见 [DEPLOY_TO_HMMNC.md](./DEPLOY_TO_HMMNC.md) 和 [CODEX_HANDOFF.md](./CODEX_HANDOFF.md)。

## 替换真实图片

只需将农场实际照片裁剪到约16:9，并转为 WebP（建议单张不超过500KB），**以相同文件名替换 `assets/images/` 中对应文件**，再重新构建。网站不需要修改图片路径。
